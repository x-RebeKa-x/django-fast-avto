2. КАКИЕ ДАННЫЕ МЫ СОБИРАЕМ

2.1. Персональные данные, предоставляемые Пользователем добровольно:
  • Для арендаторов (водителей): Имя, фамилия, контактный телефон, адрес электронной почты. В отдельных случаях (при бронировании через сайт) — данные паспорта и водительского удостоверения (серия, номер), необходимые для заключения договора аренды с Арендодателем.
  • Для арендодателей (партнеров/частников): Имя, контактный телефон, e-mail, реквизиты компании/ИНН (для юрлиц), данные паспорта (для физлиц), данные документов на автомобиль (СТС), банковские реквизиты (если предусмотрены выплаты).
2.2. Данные, собираемые автоматически:
  • Технические данные: IP-адрес, тип браузера, операционная система, разрешение экрана.
  • Данные о поведении: история переходов по страницам, клики, время посещения.
  • Данные об устройстве: модель мобильного телефона, идентификатор устройства (для мобильных приложений).
  • Данные геолокации (при наличии согласия Пользователя).
  • Файлы cookie.
2.3. Обезличенные данные:
  • Статистические данные, которые не позволяют идентифицировать конкретного человека и используются для анализа работы Сайта.

3. ЦЕЛИ СБОРА И ОБРАБОТКИ ДАННЫХ

3.1. Оказание услуг и предоставление функционала Сайта:

  • Передача данных Арендодателю (если Пользователь выбрал конкретный автомобиль) для оформления договора аренды.
3.2. Улучшение качества сервиса:
  • Анализ поведения Пользователей для оптимизации интерфейса.
  • Сбор статистики посещаемости.
3.3. Маркетинг и реклама:

3.4. Безопасность:

  • Подтверждение личности Пользователя.

Мы обрабатываем ваши данные только тогда, когда для этого есть законное основание:

5.1. Мы не продаем персональные данные Пользователей.
